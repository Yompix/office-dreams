# Стрим на YouTube через OBS

## 1. Подключение (OBS → Настройки → Трансляция)
- Сервис: YouTube - RTMPS (или «Настраиваемый…»)
- Сервер: rtmp://a.rtmp.youtube.com/live2
- Ключ потока: скопируй в YouTube Studio → «Начать трансляцию» → «Ключ трансляции». Вставляй только в OBS и никому не отправляй (даже мне): с ключом любой может вести эфир на твоём канале.

## 2. Настройки (OBS → Настройки)
- Вывод → Кодировщик: NVIDIA NVENC H.264 (если видеокарта NVIDIA), иначе x264
- Битрейт: 6000 Кбит/с (1080p 60 к/с) или 4500 (1080p 30 / 720p 60)
- Интервал ключевых кадров: 2 с
- Аудио: 160 Кбит/с
- Видео: базовое и выходное разрешение 1920×1080, 60 (или 30) FPS

## 3. Сцены (добавь 4 сцены, источник «Изображение» = файлы из этой папки)
1. **Скоро начнётся** — starting.png (+ музыка)
2. **Игра** — «Захват игры» (снизу) → «Видеозахват» камеры → overlay.png (сверху). Камеру поставь в зелёную рамку справа внизу (480×270)
3. **Отошёл** — brb.png
4. **Конец** — ending.png

## 4. Превью
thumbnail.png — шаблон превью 1280×720 (могу под каждый стрим сделать с названием игры — просто напиши игру).

## 5. Чат на экране (по желанию)
YouTube Studio → трансляция → «Чат» → ссылка на всплывающий чат → в OBS источник «Браузер» с этой ссылкой.
