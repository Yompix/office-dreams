LANTERN 1.5.0 для Windows — by Yompix

Играйте с друзьями по коду комнаты — в Minecraft: Java Edition и Bedrock Edition.

Как запустить: распакуйте архив в любую папку и откройте LANTERN.exe.
Если Windows пишет «Windows защитила компьютер» — «Подробнее» → «Выполнить в любом случае»
(программа пока без платной цифровой подписи).

Для игры нужна своя копия Minecraft. LANTERN не содержит файлов игры.
Серверы (Paper, Geyser, Bedrock Dedicated Server) и Java скачиваются по вашему запросу
с официальных сайтов; запуск сервера — только после согласия с Minecraft EULA.
