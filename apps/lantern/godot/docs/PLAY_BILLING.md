# Покупки Google Play в LANTERN 2.0 — что сделать владельцу

Код готов: в Android-сборке есть плагин `LanternBilling` (Google Play Billing Library 8.3.0; до 2.0.4 — 7.1.1), сервер LANTERN
проверяет каждую покупку у Google (`relay/billing.js`) и только потом начисляет. **Пока вы не сделаете шаги ниже,
настоящие покупки не работают** (в приложении платное просто не показывается; ДЕМО-режим для проверки остаётся).

Как это устроено: приложение показывает окно оплаты Google Play → получает токен покупки → отправляет на сервер
LANTERN → сервер спрашивает Google (Google Play Developer API), подтверждает покупку (acknowledge) и начисляет →
для искр приложение «расходует» покупку (их можно купить снова). Один токен — одно начисление; чужой токен не примут.

## Что продаём
| ID товара (вводить ровно так) | Тип | Что даёт |
|---|---|---|
| `lantern_pro_month` | Подписка, месяц | **LANTERN Plus**: без рекламы, свой код комнаты, облачные копии миров, 32 места в сети «Любые игры» (бесплатно — 16), особая косметика |
| `lantern_pass_s1` | Разовая покупка | Пропуск сезона «Первые огни» |
| `sparks_500` | Разовая, расходуемая | 500 искр (косметика) |
| `sparks_1200` | Разовая, расходуемая | 1200 искр |

Бесплатно остаётся всё главное: комнаты Minecraft, «Любые игры» (до 16 человек), друзья, чат, «Найти игроков».
На ПК покупок нет (там нет Google Play): «Plus» привязан к профилю LANTERN и действует там, где вы вошли этим профилем.

## Шаги в Play Console (по порядку)
1. **Платёжный профиль.** Play Console → «Настройка» → «Платёжный профиль» → создать (нужен для любых платных товаров).
   Для Украины Google выплачивает на банковский счёт; заполните налоговую информацию, если попросит.
2. **Загрузите сборку с покупками хотя бы во «Внутреннее тестирование».** Товары можно создать только после того,
   как в Play есть сборка с разрешением BILLING. Соберите AAB (в Godot: экспорт «Android AAB») и подпишите вашим ключом загрузки
   (`lantern-upload.jks`, см. PLAY_RELEASE.md) и загрузите: «Тестирование» → «Внутреннее тестирование» → «Создать выпуск».
3. **Подписка.** «Монетизация» → «Товары» → «Подписки» → «Создать подписку»:
   ID `lantern_pro_month`, название «LANTERN Plus» → «Добавить базовый тариф»: ID `monthly`, «Автопродление», период
   «1 месяц», цена (например 99,99 ₴; Google сам пересчитает для других стран) → «Активировать».
4. **Разовые товары.** «Монетизация» → «Товары» → «Внутриигровые товары» → «Создать товар» — три раза:
   `lantern_pass_s1`, `sparks_500`, `sparks_1200`; название, описание, цена → «Сохранить» → «Активировать».
5. **Сервисный аккаунт для проверки покупок (ключ для сервера).**
   1. https://console.cloud.google.com → выберите (или создайте) проект → «APIs & Services» → «Library» →
      найдите **Google Play Android Developer API** → «Enable».
   2. «IAM & Admin» → «Service Accounts» → «Create service account», имя `lantern-billing` → «Done».
   3. Откройте его → «Keys» → «Add key» → «Create new key» → **JSON** → файл скачается. Это секрет: никому не
      отправляйте, в git и в чат не кладите.
   4. Play Console → «Пользователи и разрешения» → «Пригласить пользователей» → e-mail сервисного аккаунта
      (вида `lantern-billing@<проект>.iam.gserviceaccount.com`) → «Разрешения для приложений» → LANTERN →
      отметить «Просмотр финансовых данных» и «Управление заказами и подписками» → «Пригласить».
      (Права начинают действовать не сразу — иногда до 24 часов.)
6. **Ключ — на Railway.** Railway → проект сайта → сервис → «Variables» → «New Variable»:
   - `GOOGLE_SERVICE_ACCOUNT_JSON` = **всё содержимое** скачанного JSON-файла (открыть Блокнотом, выделить всё, вставить);
   - (не обязательно) `LANTERN_PACKAGE` = `com.yompix.lantern` — это и так значение по умолчанию;
   - `DEMO_PURCHASES` = `0` — выключить ДЕМО-покупки на сервере, когда пойдёте в открытый доступ.
   Сохраните — Railway перезапустит сайт сам.
7. **Тестовые покупатели.** Play Console → «Настройка» → «Тестирование лицензий» → добавьте свой Gmail →
   «Ответ на лицензию: RESPOND_NORMALLY». Такие покупки бесплатные и помечены «Тест».
8. **Проверка.** Установите LANTERN из ссылки внутреннего тестирования (не APK!) → «Магазин» → «LANTERN Plus» →
   оплата тестовой картой → профиль показывает «LANTERN Plus». Если не начислилось — «Настройки» → «Сообщить о
   проблеме», в журнале будет `billing: сервер: <код>`:
   `billing_not_configured` — нет переменной на Railway; `google_401/403` — сервисному аккаунту ещё не дали права
   (шаг 5.4, подождите); `not_paid` — оплата ещё не прошла (наличные и т. п.).

## 6. Декларации Play для 2.0 (иначе выпуск отклонят)
- «Политика приложения» → «Содержимое приложения» → **VPN-сервис (VpnService)**: «Да»; объяснение:
  «Основная функция LANTERN — виртуальная локальная сеть для игры с друзьями. VPN создаёт сеть 10.88.x.x только между
  участниками комнаты; остальной интернет-трафик через VPN не идёт, не изменяется и не собирается.» Приложите видео
  «Создать сеть → Подключить → запрос VPN → игра видит друга».
- **Службы переднего плана**: `specialUse` (уже было в 1.3) — то же объяснение про игру с друзьями.
- **Безопасность данных**: добавьте «IP-адрес (для прямого соединения между участниками сети, не хранится)».

## Что НЕ сделано и почему
- Настоящую покупку здесь проверить нельзя: нужны товары в вашей Play Console, сборка из Play и ваш ключ.
  Серверная проверка протестирована против поддельного Google (`relay/test_billing.js`: подписка, искры один раз,
  чужой токен, неоплаченное, без ключа).
- Продление подписки: при каждом запуске приложение заново отправляет активные покупки (`restore`), сервер продлевает
  «Plus» до даты окончания у Google. Уведомления Google в реальном времени (RTDN) не подключены — не обязательно.
- Возвраты денег: если вернёте деньги в Play Console, «Plus» досидит до конца оплаченного месяца (без RTDN).
