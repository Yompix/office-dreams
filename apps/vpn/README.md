# VPN YURK (Юрк, бот @yurkvpn_bot) — свой VPN на продажу

Продаётся через Telegram-бота за звёзды. Пользователь получает **ссылку-подписку** и вставляет её в бесплатное приложение
(Happ, Hiddify, v2RayTun, Streisand, v2rayNG): все серверы и протоколы подтягиваются сами.

**Почему проходит блокировки:**
- **VLESS + Reality** (TCP 443): для DPI соединение выглядит как обычный заход на www.microsoft.com. Основной протокол.
- **Hysteria2** (UDP 443, ⚡ в списке): очень быстрый на мобильном интернете и при потерях пакетов.

Торренты на серверах блокируются: без этого хостинг банит сервер за жалобы.

## Из чего состоит

| Папка | Что это |
|---|---|
| `panel/` | Панель на Node.js без npm-пакетов: бот (меню, 3 дня бесплатно, оплата звёздами, рефералы +7 дней, напоминание за сутки до конца), ссылки-подписки, страница «подключить в один клик», выдача настроек узлам. База — SQLite. |
| `panel/node/install.sh` | Ставит узел на чистый Ubuntu/Debian: Xray + Hysteria2 + BBR + агент. |
| `panel/node/agent.sh` | Раз в минуту берёт с панели список оплативших и перезапускает службу, только если список изменился. |
| `docs/PLAN.md` | План: запуск, цены, что дальше (своё приложение и т.д.). |

## Запуск

**1. Бот.** В @BotFather: `/newbot` → получить `BOT_TOKEN`. Платежи звёздами подключать не нужно.

**2. Панель на Railway.** New Service → этот репозиторий → Root Directory `apps/vpn/panel`, Start `node server.js`.
Добавить Volume `/data`. Переменные — из `panel/.env.example` (`BOT_TOKEN`, `BOT_USERNAME`, `PUBLIC_URL`, `ADMIN_IDS`, `ADMIN_KEY`).
Панель сама поставит вебхук бота.

**3. Сервер (узел).** Купить VPS (Ubuntu 22/24, 1 ГБ RAM, от ~$4–6/мес) **вне страны, где блокируют**: Нидерланды, Финляндия, Германия.
В боте написать: `/addnode 🇳🇱Нидерланды 1.2.3.4`. Бот пришлёт команду. Выполнить её на сервере под root.
Через минуту в `/nodes` узел должен быть «на связи».

**4. Проверка.** В боте нажать «🎁 Бесплатно» → «Мой ключ» → «Подключить в один клик» → выбрать Happ.

## Команды админа (в боте)

`/money` — доход, расход Railway, сколько отложить и сколько забрать себе (приходит и сам каждый день в 06:00 UTC) · `/stats` — пользователи, оплаты, звёзды · `/nodes` — узлы · `/addnode Имя IP [сайт-маска]` · `/node_off N`, `/node_on N` · `/give id дней` — подарить дни.

## На своём ПК

```
cd apps/vpn/panel
node test.js
BOT_TOKEN=... BOT_USERNAME=... node server.js
```
Без `https` в `PUBLIC_URL` бот работает через long polling. Но ссылки-подписки должны вести на настоящий адрес, так что продавать — только с Railway или своего сервера.
