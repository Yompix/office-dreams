# Office Dreams — Telegram Mini App

Неонова піксельна гра-тайкун: гравець будує ігрову студію (команда → ігри → поверхи → IPO), а за **справжній** прогрес отримує **бали аірдропу** для майбутнього токена на TON. Є онлайн-сервер, друзі-реферали, щоденні відмітки, завдання, рейтинг, магазин за Telegram Stars, підключення TON-гаманця і захист від ботів. Мови: English / Русский / Українська (визначаються автоматично з Telegram).

> Простими словами: гра — це «завод», а бали — «зарплата» за реальну роботу. Скільки б людей не прийшло, «касу» не можна надрукувати: бали ростуть повільніше, якщо гравець за день «гриндить», а боти отримують нуль.

## Що всередині

| Папка / файл | Що це |
|---|---|
| `src/engine.js` | Логіка гри (однакова в браузері й на сервері — сервер перевіряє кожну дію гравця) |
| `src/ui_*.js`, `src/style.css`, `src/render.js` | Інтерфейс, піксельна графіка, ефекти |
| `src/lang_en.js`, `lang_ru.js`, `lang_uk.js` | Переклади (505 рядків кожною мовою) |
| `server/` | Сервер на чистому Node.js: вхід через Telegram, збереження, бали, реферали, завдання, Stars, антибот, адмінка |
| `public/` | Картинки для BotFather (обкладинка 640×360, аватар 640×640, іконка) |
| `scripts/setup-bot.js` | Перевіряє налаштування і реєструє бота в Telegram |
| `test/` | Тести (сервер, економіка, антибот, переклади, події, повний прогін у браузері) |

Жодних npm-пакетів не потрібно — тільки **Node.js 22.13 або новіший** (вбудована база SQLite).

## Запуск за 5 кроків

### 1. Створи бота в @BotFather

1. `/newbot` → придумай ім’я і username (наприклад `OfficeDreamsBot`). Отримаєш **BOT_TOKEN** — нікому його не показуй.
2. `/setuserpic` → завантаж `public/avatar-640.png`.
3. `/newapp` → обери свого бота → назва `Office Dreams` → опис → фото **`public/cover-640x360.png`** → GIF пропусти (`/empty`) → **URL** = адреса твого сервера (крок 2, напр. `https://game.example.com`) → **short name** = `play`.
   Посилання на гру буде: `https://t.me/<бот>/play`.
4. Платежі за Telegram Stars окремо підключати не треба — вони працюють одразу.

### 2. Сервер з HTTPS

Telegram відкриває Mini App **тільки по HTTPS**. Два прості варіанти:

**Варіант A — VPS (Hetzner, DigitalOcean, Contabo… від ~5 $/міс) + Docker:**
1. Купи домен (або піддомен) і направ його A-запис на IP сервера.
2. На сервері: `git clone …` (або завантаж архів), `cd office-dreams`.
3. `cp .env.example .env` і заповни (крок 3).
4. У файлі `Caddyfile` заміни `game.example.com` на свій домен.
5. `docker compose up -d` — Caddy сам отримає безкоштовний HTTPS-сертифікат.

**Варіант B — Railway (без свого сервера):**
1. Завантаж проєкт у свій GitHub-репозиторій → у Railway «New Project → Deploy from GitHub».
2. Додай **Volume** з шляхом монтування `/app/data` (там живе база — без цього прогрес зникне при перезапуску!).
3. У Variables додай змінні з `.env.example`, а в Settings → Networking увімкни публічний домен; його `https://…` встав у `PUBLIC_URL`.

### 3. Заповни `.env`

Мінімум: `BOT_TOKEN`, `BOT_USERNAME`, `APP_SHORTNAME=play`, `PUBLIC_URL`, `SESSION_SECRET`, `ADMIN_KEY`.
Випадковий рядок для секретів: `node -e "console.log(require('crypto').randomBytes(32).toString('hex'))"`.
`DEV_AUTH` на робочому сервері **завжди 0**.

### 4. Зареєструй бота

```
npm run setup-bot
```
Скрипт перевірить токен, домен і версію Node, поставить кнопку «Play», команди й описи трьома мовами, вебхук, і покаже готові посилання. Сервер також робить це сам при кожному старті.

### 5. Канал і спільнота (необов’язково)

Щоб працювало завдання «Підпишись на канал», додай бота **адміністратором** каналу і заповни `CHANNEL=@твій_канал` та `CHANNEL_URL=https://t.me/твій_канал`. `CHAT_URL` і `X_URL` додають ще два завдання.

Готово: відкрий `https://t.me/<бот>/play` — гра запуститься онлайн.

## Як працює економіка (коротко)

- **Бали дає тільки підтверджений сервером прогрес**: релізи ігор, покращення, квести, цілі, поверхи, щоденні завдання, відмітки, активні друзі. Тапи майже нічого не дають (0,02 бала).
- **М’яка денна стеля** (`POINTS_DAILY_D=300`): що більше граєш за день, то менше дає кожна нова дія. Регулярна гра вигідніша за гринд, а ферма з 1000 акаунтів не може «надрукувати» бали.
- **Сервер — суддя**: телефон шле лише список дій, сервер перераховує гру сам. Неможливо прискорити час, підробити гроші чи рахунок.
- **Друзі**: 10% від балів друга + 2% від друзів друзів (з загального пулу, з ліміту 150/день). Друг стає «активним» лише після 2 днів гри й випуску гри; за нього запрошувач отримує бонус і ігрові $500 + 2 кристали.
- **Магазин Stars** дає тільки ігрові предмети (кристали, стартовий набір, Office Pass +25% до денної стелі). Бали за гроші не продаються — це важливо і для чесності, і юридично.
- Деталі з цифрами — у документі «Токеноміка та онлайн Office Dreams».

## Реклама за нагороду (Adsgram)

1. Зареєструйся на partner.adsgram.ai, додай свій Mini App і створи блок типу **Reward**.
2. Встав його номер у змінну `ADSGRAM_BLOCK_ID` — у грі з'явиться кнопка «Переглянути рекламу».
3. Нагорода за перегляд: повна енергія + ігрові $ + 4 бали; не більше 8 разів на день і раз на 45 с (змінні `ADS_*`).
4. Бали за рекламу — це шматок того самого фіксованого пирога, нових токенів вони не створюють. Дохід від реклами враховується в «гальмі емісії».

## Захист від ботів

Перевірка підпису Telegram, сесії з терміном дії, ліміти запитів, перевірка часу (не можна «прокрутити» гру), статистика ритму тапів (автоклікери), цілодобова активність, однакові пристрої/IP, ферми рефералів і сплески запрошень, однакові гаманці, сигнали Premium/username. Підозрілі акаунти спершу отримують половину балів і коротку перевірку «натисни на зайвий емодзі», явні боти — нуль. Усе видно й можна виправити вручну в адмінці.

Чесно: повністю зупинити людину з сотнею справжніх акаунтів неможливо — тому економіка влаштована так, щоб навіть така ферма приносила мізер.

## Адмінка

`https://твій-домен/admin` → введи `ADMIN_KEY`. Там: статистика (гравці, DAU, бали за день, дохід у Stars), список підозрілих акаунтів з причинами, ручне «ок / бан», вивантаження знімка балів (CSV/JSON) — саме з нього в майбутньому робиться розподіл токенів.

## Перед запуском токена

1. Заморозь сезон і вивантаж знімок балів в адмінці.
2. Проведи аудит смарт-контракту Jetton і перевір вимоги законодавства своєї країни (бали в грі — не цінний папір і не обіцянка виплат; так написано і в самій грі).
3. Перевір підключення TON-гаманця на реальних гаманцях (Tonkeeper, Telegram Wallet).

## Для розробника

```
npm run dev          # локально без Telegram: відкрий http://localhost:8080/?dev=1
npm test             # збірка + переклади + рушій + події + сервер (32 тести)
npm run test:e2e     # повний прогін у браузері (потрібен Playwright/Chromium)
npm run build        # перезібрати dist/index.html і картинки в public/
```
