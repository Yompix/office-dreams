# ReportPlugin 0.2.0 — жалобы на игроков (Paper/Purpur 1.21.1 и 1.21.11)

Готовый плагин: `ReportPlugin-0.2.0.jar`. Один файл работает и на 1.21.1, и на 1.21.11: собран против API 1.21.1, `api-version: 1.21`.

## Установка
1. Останови сервер.
2. Замени `ReportPlugin-0.1.0.jar` на `ReportPlugin-0.2.0.jar`.
3. Запусти сервер.

База `reports.db`, `config.yml` и `messages.yml` сохраняются. Новые настройки и тексты берутся из плагина сами. Чтобы поменять их, добавь ключи из списка ниже в свой `config.yml` или `messages.yml`.

## Что нового

### Быстрая жалоба: Shift + ПКМ по игроку
- **Как открыть:** зажми Shift и нажми ПКМ по игроку рядом (до 4 блоков). Откроется меню «Жалоба на <ник>»: голова игрока и 5 причин — читы, гриферство, оскорбления, спам, другое.
- **Как отправить:**
  1. Первый клик по причине выбирает её: кнопка светится, появляется «▶ Нажми ещё раз, чтобы отправить».
  2. Второй клик отправляет жалобу.

  Так случайный клик жалобу не отправит.
- **После отправки:** в чате кликабельная подсказка «добавить подробности» — откроет `/report comment <номер> `.
- **`/report <ник>` без причины** открывает то же меню.
- **Когда меню не открывается:**
  - по NPC (Citizens, ShopNpc и т. п.);
  - по невидимым (ваниш) игрокам и по себе;
  - без права `reportplugin.report`;
  - дальше `max-distance`;
  - если другой плагин уже отменил это нажатие.
- **Shift на 1.21.11:** проверяется и `isSneaking()`, и текущий ввод игрока. Без этого на 1.21.11 Shift иногда не замечался.

### Защита от спама
- **Повтор на того же игрока не создаётся:** «У вас уже есть открытая жалоба #N… Дополнить её: /report comment N».
- **Жалобы разных игроков объединяются:** если на игрока уже есть открытая жалоба, новая прикрепляется к ней как дубликат. Модератор видит одну жалобу с «(+1)» и список, кто ещё пожаловался. Объединение было заложено в базе 0.1.0, но не использовалось.
- **Пауза между жалобами** одного игрока: `report-cooldown-seconds`, по умолчанию 60.
- **Лимит открытых жалоб** у игрока: `max-open-reports-per-player`, по умолчанию 5.
- **Модераторам** повторная жалоба приходит короткой строкой «Ещё жалоба на X → добавлена к #N».
- **Новое право** `reportplugin.bypass-limits` (по умолчанию op) — без паузы и лимита.

### Исправление
- Очистка текста убирает коды цвета целиком. Раньше от `§c` оставалась буква `c`.

## Проверка безопасности
Проверял весь код.
- **SQL-инъекции:** только подготовленные запросы. Подстановки в текст запросов — константы. Есть тест со строкой `'); DELETE FROM reports; --`.
- **Цвета и форматирование:** ники, комментарии и причины выводятся простым текстом, подменить цвета или вставить кликабельные команды нельзя. Коды `§` и невидимые символы вырезаются. Длина ограничена `max-text-length`.
- **Ник цели:** только `[A-Za-z0-9_]{1,16}`, жалоба только на известного игрока, на себя нельзя.
- **Права:** каждая команда `/reports` проверяет своё право. Чужие жалобы отправитель не видит.
- **Защищённое меню:** клики, перетаскивание и Shift-клики в меню отменены. Нажимать может только владелец меню. Повторная отправка из одного меню заблокирована.
- **Работа с базой:** в отдельном потоке, сервер не тормозит. История действий в базе только дописывается.
- **Что осталось:** ники Bedrock (Floodgate, с точкой в начале) не проходят проверку ника — так было и в 0.1.0.

## Новые настройки (`config.yml`)
```yaml
report-cooldown-seconds: 60
max-open-reports-per-player: 5
quick-report:
  enabled: true
  require-sneak: true   # false — меню по обычному ПКМ
  max-distance: 4
```
Новые тексты лежат в `messages.yml` в разделе `quick:` и в ключах `report.duplicate-own`, `report.cooldown`, `report.too-many`, `report.add-comment-hint`, `notify.duplicate`.

## Как проверялось
- **Тесты** `mvn test` — 10, на настоящей SQLite:
  - создание жалобы;
  - отказ при повторе от того же игрока;
  - объединение с жалобой другого игрока;
  - пауза и лимит;
  - жалоба на себя, неизвестный и некорректный ник;
  - SQL-строка сохраняется как обычный текст;
  - очистка текста.
- **Сервер Paper 1.21.11**, три бота-игрока (`test-bot/`):
  - без Shift меню не открывается, с Shift — открывается;
  - выбор причины и отправка;
  - модератор получил уведомление;
  - повтор отклонён;
  - вторая жалоба от другого игрока прикрепилась: «(+1)», «Дубликатов: 1 (Third)»;
  - пауза сработала;
  - `/reports` и `/reports open` работают.
- **Сервер Paper 1.21.1:** плагин запускается, команды и уведомления работают.

## Сборка
`mvn package` → `target/ReportPlugin-0.2.0.jar`. Сначала прогоняются тесты.
