# ShaderLite — журнал

## 1.0.0 (16 ноя 2026) — первая сборка
**Версия:** Minecraft 1.21.1, Fabric Loader 0.16.14. Пара Iris 1.8.8 + Sodium 0.6.13 — самая обкатанная для 1.21.1
(Iris 1.8.14 для 1.21.1 помечен beta и требует Sodium 0.8). MoreCulling взят 1.0.7: 1.0.8+ ломается с Sodium ≤ 0.6.13.
Noisium и C2ME не взяты: Noisium помечен как серверный (client: unsupported), C2ME для 1.21.1 только alpha;
оба ускоряют генерацию мира, а не отрисовку.

**Состав** (`pack/mods.json`): Fabric API, Sodium, Iris, Lithium, FerriteCore, ImmediatelyFast, EntityCulling, ModernFix,
MoreCulling, Dynamic FPS, Cloth Config, Mod Menu, RenderScale 1.2 + свой мод и шейдер.

**Лицензии:** все jar можно класть в ZIP, кроме EntityCulling (tr7zw Protective License: use/modify/compile, без права
распространения) — в ZIP вместо него `СКАЧАТЬ_ОТДЕЛЬНО.txt`, в mrpack он идёт ссылкой на cdn.modrinth.com.
Sodium — PolyForm Shield 1.0.0 (распространение разрешено с текстом лицензии). LGPL/GPL — тексты в `LICENSES/`,
ссылки на исходники в `LICENSES/СПИСОК.txt`. Тексты лицензий, которых нет внутри jar, — `pack/licenses/`.
CurseForge App не импортирует .mrpack (а для его формата нужен ключ CurseForge API) — для него инструкция через ZIP.

**Шейдер** (`shaders/ShaderLite`): GLSL 1.20, только ASCII в исходниках (Iris падал на кириллице в shaders.properties,
некоторые драйверы AMD/Intel не любят не-ASCII даже в комментариях). Проходы:
shadow (512–2048, искажение, аппаратный PCF) → gbuffers (альбедо+нормаль+свет, колыхание) → deferred (тень·N·L, `scale.deferred=0.5`)
→ deferred1 (свет + небо + туман, двусторонний апскейл по глубине) → вода/частицы вперёд (со своим туманом) →
composite..2 (bloom + лучи в 1/4) → final (CAS, ACES, цвет). Отдельного прохода тумана нет (слит в освещение).
Важно: `size.buffer` вместе с `scale.*` в Iris 1.8.8 давал свет только в четверти экрана — буферы полноразмерные,
уменьшенный проход пишет в левый нижний угол, читаем `texcoord * scale`.

**Мод «Адаптивное качество»** (`mod/`): без миксинов, Fabric API события. Лесенка: облака → дальность −2 → частицы →
дальность → сущности 75 % → частицы мин. → дальность → сущности 50 % → дальность до минимума. Падение — 2 секунды ниже
92 % цели; подъём — 6+ секунд выше 130 % (с удвоением ожидания, если сразу снова упало). Пауза в меню/при неактивном
окне. Свои значения в options.txt не попадают: перед экранами настроек, при выходе из мира и игры возвращает базу.
Параметры шейдера на лету не меняет (Iris API v0 умеет только вкл/выкл шейдер).

**Сборка без Gradle:** javac против Minecraft с yarn-именами (tiny-remapper), потом ремап в intermediary —
~30 МБ вместо ~1 ГБ кэша Loom. Клиент для проверки — свой лаунчер (`tools/setup_client.py`) без звуков.

Вид 1 — лес и река с высоты (-32 80 0, взгляд на запад), вид 2 — с высоты 100 на гору и воду (сырые строки — `bench_raw.txt`).

Компиляция: все профили (МИНИМУМ/НИЗКИЙ/СРЕДНИЙ/ВЫСОКИЙ), Незер и Энд — без ошибок в логе Iris.

## Не проверено / риски
- Настоящие видеокарты (Intel HD/UHD, AMD, NVIDIA), Windows и macOS — только Mesa llvmpipe под Linux.
- Импорт .mrpack в Modrinth App/Prism руками не делали (формат собран по спецификации, sha512 и ссылки проверены при скачивании).
- Незер и Энд — только «компилируется и выглядит прилично», без полировки.
- RenderScale + Iris работает на llvmpipe; автор пишет, что «динамический» режим с шейдерами выключен — у нас фиксированный масштаб.
- Ванильный options.txt в overrides: при обновлении сборки лаунчер может перезаписать дальность/облака.
