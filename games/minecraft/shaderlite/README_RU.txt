ЛЁГКИЕ ШЕЙДЕРЫ (ShaderLite) 1.0 — красивые шейдеры для слабых ноутбуков и ПК
=============================================================================

Только для Minecraft JAVA Edition 1.21.1 (ПК: Windows, Linux, macOS).
Не работает в Bedrock (Windows-версия из Microsoft Store, телефоны, консоли).

Что внутри
----------
* Sodium + Iris — быстрый движок отрисовки и загрузчик шейдеров.
* Оптимизации: Lithium, FerriteCore, ImmediatelyFast, EntityCulling, ModernFix, MoreCulling, Dynamic FPS.
* RenderScale — рисует мир в уменьшенном разрешении (интерфейс остаётся чётким).
* Mod Menu — кнопка «Моды» в меню, чтобы настраивать моды.
* Свой шейдерпак ShaderLite (написан с нуля): тени, мягкий свет, вода с волнами и отражением неба,
  закаты, туман, свечение, колышущиеся листва и трава, цветокоррекция, резкость.
* Свой мод «Адаптивное качество»: держит нужный FPS (по умолчанию 40), сам на время снижает облака,
  дальность прорисовки, частицы — и возвращает, когда FPS снова хватает.

Честно о чудесах
----------------
Шейдер — это дополнительная работа для видеокарты. Даже самый лёгкий шейдер съедает часть FPS.
Мы сделали так, чтобы он съедал как можно меньше: тени и свет считаются в половинном разрешении
(в 4 раза меньше работы), свечение — в четверти, вода и небо — формулами без текстур.
Если без шейдеров у вас 30 FPS, с шейдером будет меньше. Сборка выжимает максимум, но не волшебство.


1. УСТАНОВКА ЧЕРЕЗ MODRINTH APP (проще всего)
---------------------------------------------
1) Скачайте Modrinth App: https://modrinth.com/app (бесплатно) и войдите в аккаунт Microsoft
   (нужна купленная Minecraft Java).
2) В Modrinth App: слева «+» (Create instance) -> вкладка «Import from file» / «Из файла»
   -> выберите файл ShaderLite-1.0.0.mrpack. (Или просто перетащите файл в окно.)
3) Подождите, пока скачаются моды (около 15 МБ). Нажмите «Играть».
Шейдер уже включён, профиль НИЗКИЙ.

То же самое умеют Prism Launcher (Добавить экземпляр -> Импорт -> файл .mrpack) и ATLauncher.

CurseForge App файлы .mrpack не открывает. Для CurseForge — способ 2 ниже:
CurseForge -> Minecraft -> «Create Custom Profile» -> версия 1.21.1, загрузчик Fabric ->
в профиле «...» -> «Open Folder» -> положите туда содержимое ZIP (папки mods, config, shaderpacks).


2. УСТАНОВКА ИЗ ПРОСТОГО ZIP (любой лаунчер)
--------------------------------------------
1) Поставьте Fabric для 1.21.1: https://fabricmc.net/use/installer/ -> Client -> версия 1.21.1 -> Install.
2) Откройте папку игры (%appdata%\.minecraft на Windows; в лаунчере обычно есть кнопка «Открыть папку»).
3) Распакуйте ShaderLite-mods-1.0.0.zip прямо в эту папку (папки mods, config, shaderpacks).
   Если в mods уже есть другие моды для другой версии — уберите их.
4) Один мод (EntityCulling) автор запрещает класть в чужие архивы — его ссылка в файле
   СКАЧАТЬ_ОТДЕЛЬНО.txt. Скачайте и положите в mods. Без него сборка тоже работает, просто чуть медленнее.
5) В лаунчере выберите профиль «fabric-loader-1.21.1» и играйте.

Только шейдер, без сборки: файл ShaderLite_v1.0.zip положите в папку shaderpacks
(нужны Iris + Sodium для 1.21.1; с OptiFine не проверялся).


3. КАК ВКЛЮЧИТЬ / НАСТРОИТЬ ШЕЙДЕР
---------------------------------
Настройки -> Настройки графики -> Пакеты шейдеров (или клавиша O в игре).
Выберите ShaderLite_v1.0.zip -> «Применить». Кнопка «Настройки шейдера» -> «Профиль»:

  МИНИМУМ  — без теней. Intel HD 4000 / HD 4600 / HD 520, старые ноутбуки.
  НИЗКИЙ   — (по умолчанию) тени 512, свет в половинном разрешении.
             Intel UHD 620/630, Iris Xe, AMD Vega 3/8, GT 710/730, ноутбуки 2017+.
  СРЕДНИЙ  — тени 1024 мягкие, лучи солнца. GTX 750 Ti / 950 / 1050, RX 550/560, Radeon 680M/780M.
  ВЫСОКИЙ  — тени 2048, свет в полном разрешении. GTX 1060 / RX 570 и мощнее.

Внутри разделы «Свет и тени», «Мир», «Картинка» — всё подписано по-русски.
Самое дорогое — «Тени». Не тянет? Выключите тени или поставьте профиль МИНИМУМ.


4. ЕСЛИ МАЛО FPS — ПО ПОРЯДКУ
-----------------------------
1) Профиль шейдера ниже (ВЫСОКИЙ -> СРЕДНИЙ -> НИЗКИЙ -> МИНИМУМ).
2) RenderScale: в игре нажмите U (или Моды -> RenderScale) и поставьте масштаб 0.75 или 0.5:
   мир рисуется в меньшем разрешении, интерфейс остаётся чётким. Это самый сильный рычаг
   на слабой встройке (см. замеры). Резкость в шейдере (CAS) частично возвращает чёткость.
3) Дальность прорисовки 6–8 чанков (шейдерные тени всё равно дальше 3–8 чанков не видны).
4) Sodium: Настройки графики -> Качество -> Листва: «Быстро» — заметный плюс на встройке.
5) Ноутбук: играйте от розетки, в Windows «Максимальная производительность»;
   для NVIDIA/AMD выберите для Java (javaw.exe) «Высокопроизводительный процессор» в настройках графики Windows.
6) Памяти Minecraft хватает 3–4 ГБ (в Modrinth App: Настройки экземпляра -> Java -> Память).

«Адаптивное качество»: Моды -> ShaderLite: Adaptive Quality -> кнопка настроек.
Можно выключить, выбрать нужный FPS (30/40/60...) и минимальную дальность.
Или в файле config/shaderlite-adaptive.properties: enabled=false.
Ваши настройки мод не портит: в файл настроек всегда сохраняется ваша дальность, а не урезанная.
Параметры самого шейдера мод на лету не меняет (Iris так не умеет без перезагрузки шейдера
с подвисанием на секунды) — но тени в Iris привязаны к дальности прорисовки, так что они тоже дешевеют.


5. ЧЕСТНО ПРО INTEL HD 4000 И ПОХОЖИЕ
-------------------------------------
HD 4000 / HD 2500 (2012–2013 гг.) — очень слабая видеокарта. Без шейдеров с Sodium на ней
обычно 40–60 FPS при дальности 6–8. С шейдерами:
  * профиль МИНИМУМ + RenderScale 0.5–0.75 + дальность 6 — играбельно (примерно 25–40 FPS в зависимости от ноутбука);
  * НИЗКИЙ с тенями — скорее 15–25 FPS, это уже на любителя;
  * СРЕДНИЙ/ВЫСОКИЙ — не для неё.
На macOS старые Intel дают только OpenGL 2.1 — шейдер написан на GLSL 1.20 как раз для этого,
но на реальном Mac мы его не проверяли.
Это оценка, а не замер на реальной HD 4000 — у нас такой видеокарты не было (см. «Замеры»).


6. ЗАМЕРЫ
---------
Где мерили: программная видеокарта Mesa llvmpipe (видеокарту изображает процессор, 4 ядра), 1280x720,
дальность 8 чанков, один и тот же мир и ракурс, 20 секунд на замер.
llvmpipe НЕ равна настоящей видеокарте — абсолютные FPS к вашему ПК не относятся,
смотрите на ОТНОСИТЕЛЬНУЮ разницу между строками.

Вид 1 — лес и река с высоты (много геометрии), вид 2 — гора и вода с высоты. FPS (больше — лучше):

                                                   вид 1    вид 2   время кадра, вид 1
  Обычный Minecraft, без модов                      14.4     15.6      70 мс
  Сборка без шейдера (Sodium и оптимизации)         15.2     17.5      66 мс
  ShaderLite МИНИМУМ                                 8.9     10.8     112 мс
  ShaderLite НИЗКИЙ                                  6.0      9.1     166 мс
  ShaderLite СРЕДНИЙ                                 5.0      8.1     199 мс
  ShaderLite ВЫСОКИЙ                                 3.5      6.2     285 мс
  НИЗКИЙ + RenderScale 0.5                           9.6     15.4     105 мс
  МИНИМУМ + RenderScale 0.5                         14.3     18.2      70 мс
  НИЗКИЙ + «Адаптивное качество» (цель 40 FPS)      ~9.3       —      ~107 мс  (сам снизил дальность 8 -> 4, облака)
  НИЗКИЙ, но только Sodium + Iris без оптимизаций    5.2      9.0     191 мс

Что из этого следует:
  * Шейдер стоит FPS всегда: МИНИМУМ ~ -40%, НИЗКИЙ ~ -45..60% от игры без шейдера (на llvmpipe).
  * RenderScale 0.5 почти удваивает FPS: МИНИМУМ + RenderScale 0.5 работает так же быстро, как игра
    вообще без шейдеров. Это главный рычаг для слабой встройки (цена — картинка мягче).
  * Оптимизации без шейдеров на llvmpipe дают только +5..12%: тут всё упирается в «видеокарту»
    (процессор рисует пиксели). На настоящей видеокарте Sodium обычно даёт в разы больше — это его сильная сторона.
  * Свет в половинном разрешении на llvmpipe дал всего +2..7% на НИЗКОМ (там тень — 1 выборка, дешёвая);
    сильнее он помогает на СРЕДНЕМ/ВЫСОКОМ с 4–8 выборками. Основная цена теней здесь — второй проход
    геометрии (мир рисуется ещё раз со стороны солнца); поэтому профиль МИНИМУМ без теней и есть «спасение» для HD 4000.


7. ЕСЛИ ХОТИТЕ ЧУЖИЕ ШЕЙДЕРЫ НА СЛАБОМ ПК
-----------------------------------------
Чужие шейдеры мы в сборку не кладём (их лицензии), но они ставятся так же — в папку shaderpacks:
* Complementary Reimagined — профиль «Potato» или «Very Low»; тени «Off» или 512.
* BSL — профиль «Low» (а лучше «Low» + выключить Shadow, Ambient Occlusion, Volumetric Light).
* MakeUp - Ultra Fast — один из самых быстрых; профиль «Low».
* Sildur's Vibrant — версия «Lite».
Все они тяжелее ShaderLite на тех же настройках — это нормальная цена за их сложные эффекты.
