# RavageTerritory 1.5.0 (RAVAGE, Paper 1.21.11)

Территории кланов и личные базы: ядро, энергия, развитие до 5 уровня, защита, права участников, телепорт на базу.
Интеграция с ClanPlugin, WorldGuard и CombatLogX, необязательно — с AuthMe и ресурс-паком через RavageAppearance.

Готовый плагин — выбери файл под ядро сервера:
- **Paper 1.21.11** → `ravage-territory-1.5.0.jar`. Зависимости проверены на Java 21: WorldEdit 7.3.19 и WorldGuard 7.0.15. WorldEdit 7.4.x требует Java 25.
- **Paper 1.21.1** → `ravage-territory-1.5.0-mc1.21.1.jar`. Зависимости: WorldEdit 7.3.9 и WorldGuard 7.0.12.

Версию ядра видно в логе сервера: `paper-1.21.1.jar … 1.21.1-133` — это 1.21.1, а не 1.21.11.

## Установка (обновление с 1.4.4)

1. Останови сервер и сделай копию папки `plugins/RavageTerritory`. В ней `territories.db` — все территории.
2. Удали `ravage-territory-1.4.4.jar` и положи `ravage-territory-1.5.0.jar`.
3. Запусти сервер. В консоли появится строка:
   `menus.yml обновлён до 1.5.0: новых текстов N (свои правки сохранены, копия — menus.before-1.5.0.yml)`.
4. Проверь у игрока с паком: `/territory ui`.

Что сохраняется:
- `config.yml` и `progression.yml` не меняются.
- База данных та же, территории и вклады на месте.
- В `menus.yml` обновляются только тексты, которые совпадают с текстами 1.4.4. Свои названия и описания остаются.
- Слоты и материалы кнопок не трогаются: под них нарисован фон ресурс-пака.

Зависимости — те же, что у 1.4.4:
- **ClanPlugin** и **WorldGuard** (с WorldEdit) — обязательны.
- **CombatLogX** — нужен для изменений. Без него плагин из соображений безопасности блокирует постройку ядра, взносы и телепорт: «Проверка боя временно недоступна». Так было и в 1.4.4.
- **AuthMe** и **RavageAppearance** — по желанию.

## Что сделано в 1.5.0

### Интерфейс без ресурс-пака
- **Рамка меню показывает состояние ядра:** зелёная — работает, жёлтая — энергии меньше 3 часов, красная — энергии нет.
- **Полоски прогресса:** энергия, уровень ядра (■■□□□) и сбор ресурсов на расширение с процентом.
- **Подсказка «➜ что делать дальше»** в карточке базы: «Внеси ещё 32 × железных слитков», «Пополни энергию» и т. п.
- **Подсвечивается главное действие.** Если энергии мало — «Пополнить энергию», иначе — «Внести ресурсы». В подтверждении — «Подтвердить».
- **Подтверждение:** зелёная кнопка «Подтвердить» и красная «Отмена». Раньше обе были серо-красные.
- **Права участников:**
  - головы со скинами;
  - сначала участники в сети («●»), дальше по алфавиту;
  - «Разрешено» и «Запрещено» цветом вместо `true` и `false`;
  - в карточке участника его голова.
- **Кнопки нажимаются ЛКМ, ПКМ и Shift-кликом.** Раньше работал только ЛКМ.
- **У предметов меню скрыты лишние строки:** атрибуты, «Can break» и прочее.
- **Звуки:** щелчок кнопки, успех, ошибка, фанфары при постановке и улучшении ядра.
- **Для новичков:**
  - в стартовом меню кнопка «Как работает территория» с объяснением ядра, энергии, развития и прав;
  - установка ядра расписана по шагам;
  - новая команда `/territory help`.

### Ресурс-пак (RavageAppearance)
- Фон, раскладка карточек и слоты главного меню не изменились. Это проверено тестом `packLayoutUnchangedSince144`.
- Новые тексты, полоски и цвета — обычные символы, поэтому видны одинаково и с паком, и без него.
- Цветная рамка и свечение кнопок включаются только без пака, чтобы не спорить с фоном пака.

### Голограмма над ядром
- Полоска энергии, цветное состояние («Работает» / «Мало энергии» / «Истощено»), полоска уровня и размер базы.
- Тень текста, тёмная подложка и полная яркость: голограмма читается ночью и в тёмных базах.
- Текст отправляется игрокам только когда он изменился. Раньше — каждую секунду для каждого ядра.

### Границы
- Своя территория подсвечивается зелёным, чужая — красным, место для нового ядра — жёлтым. Раньше всё было красным.
- Углы территории отмечены вертикальными столбами частиц.

### Понятные причины отказа
Вместо общего «Территория защищена или действие недоступно» над хотбаром пишется причина:
- чья это территория;
- в ядре нет энергии;
- лидер ограничил права;
- изменения остановлены из-за ошибки хранилища.

### Исправления и производительность
- **Нехватка ресурсов** показывалась как `IRON_INGOT`. Теперь — «железных слитков». Добавлены русские названия для незерита, блоков, лазурита и других материалов. Незнакомый материал выводится читаемо: `oak log`, а не `OAK_LOG`.
- **Проверка AuthMe** искала класс через рефлексию каждую секунду для каждого игрока. Теперь — один раз, пока AuthMe не перезагрузится.
- **Голограммы:** убран лишний перебор всех кланов каждую секунду для каждой территории.
- **Поддержка из исходников:** плагин собран из восстановленных исходников, методы и сигнатуры классов совпадают с 1.4.4. Добавлены 14 автоматических тестов.

### Что не менялось
Защита (`Protection`), хранилище (`Store`), телепорт, вклады и улучшения, правила входа и боя работают как в 1.4.4. Изменились только тексты подсказок и звуки.

## Сборка из исходников

```
cd clanplugin-api && mvn install   # заглушка API ClanPlugin 1.4.3 (только для компиляции)
cd ../plugin && mvn package        # plugin/target/ravage-territory-1.5.0.jar (+ тесты)
mvn package -Pmc1211               # версия для Paper 1.21.1: ravage-territory-1.5.0-mc1.21.1.jar
```

Если в локальном Maven уже есть настоящий `com.irilonto:clanplugin:1.4.3`, первый шаг не нужен.
Заглушка повторяет только используемые методы: `Clan` и `ClanManager` — классы, `TerritoryLink` — интерфейс, как в оригинале.

**Заглушку `ClanPlugin-test-stub` и `combatlogx-stub` на боевой сервер не ставить.**

## Структура

| Путь | Что это |
|---|---|
| `plugin/` | исходники RavageTerritory, тесты, `pom.xml` |
| `plugin/src/main/resources/menus.yml` | тексты меню и голограммы 1.5.0 |
| `plugin/src/main/resources/defaults/menus-1.4.4.yml` | тексты 1.4.4 для переноса |
| `clanplugin-api/` | заглушка API ClanPlugin, также тестовый плагин с `/clan create/join/leave` |
| `test-stubs/` | заглушка CombatLogX и боты для проверки на сервере |
| `dist/` | готовый JAR |

## Что нужно, чтобы улучшить вид с паком

Для новых иконок, фона карточек и шрифтовых полосок пришлите:
- ресурс-пак RAVAGE (папка `assets/ravage`, шрифт `ravage:menu`);
- исходники или JAR RavageAppearance.

Без них новые картинки нельзя сделать так, чтобы они точно совпали с существующим фоном.
