# Постановка кат-сцен 1.0 «Кино» — shot list

Офлайн-постановщик `tools/shot_planner.py`. Blender на диск не поместился, поэтому вся математика — своя (подробно в начале файла).

## Как это работает

1. **Выгрузка места.** Автотест `shotexport:гл:мис:шаг` пишет `scene_*.json`:
   - воксели вокруг всех мест сцены;
   - точки актёров и камер;
   - реплики с длиной озвучки;
   - исходные планы.
2. **Биты сцены.** Длительности исходных планов сохраняются: к ним привязан таймлайн актёров. Внутри бита с пешим героем камера ставится заново:

   | План | Объектив |
   |---|---|
   | общий | 24 мм |
   | через плечо | 50 мм |
   | крупный на эмоциональной реплике | 85 мм |
   | средне-крупный | 50 мм |
   | план двоих | 35 мм |
   | финальный отъезд | 35 мм |

3. **Правила кадра:**
   - третей: глаза на верхней трети, «воздух» в сторону взгляда;
   - 180°: камера по одну сторону линии взгляда;
   - лицо не закрыто блоками и другими актёрами (плечо в «восьмёрке» — можно);
   - камере есть место;
   - два одинаковых плана одного героя подряд не ставятся.
4. **Движение камеры** — кубическая Безье с плавным разгоном и торможением: наезд, тележка, дуга, кран. Ключи каждые 0.25 с: позиция, курс, наклон, FOV, крен. Объектив переводится в вертикальный FOV кадра 16:9.
5. **В игре** (`story/Shots` → `CutsceneScreen`):
   - кривая Катмулла — Рома по ключам;
   - если герой стоит не там, где ждал планировщик, камера сдвигается вместе с ним и доворачивает кадр;
   - «ручная камера» (`hand`) — медленное покачивание на диалогах.
6. **Проверка:**
   - листы раскадровки (быстрый рендер вокселей): `--preview папка`;
   - в игре: `cine:гл:мис:шаг` с `-Dnovograd.rec=файл.mp4`, строка `[cam]`.

Без постановки (как в 0.6.6): `-Dnovograd.shots=false`.
