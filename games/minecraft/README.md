|---|---|
| `novograd/` | мод «Новоград» (GTA-город для Minecraft Java 1.21.1, Fabric): `src/`, `tools/` (сборка, звук, озвучка), `download/` |
| `lifecraft/` | мод LifeCraft (симулятор жизни), на нём вырос «Новоград» |
| `plugins/ravage-territory/` | плагин RavageTerritory (Paper 1.21.1) — готовый архив |
| `plugins/report-plugin/` | плагин ReportPlugin — готовый архив |

Перенесено сюда 9 ноя из веток `lifecraft`, `ravage-territory`, `report-plugin` (история сохранена).
Готовые сборки (`*.jar`, `*.zip`, `*.mrpack` в `*/download/`) в git не кладём — владельцу отдаём файлом; старые сборки — в истории
ветки `lifecraft`: `git show lifecraft:novograd/download/<файл> > файл`.
