# Глухомань: Порожняк

> **18+.** Тяжёлая тема (лагерная узкоколейка, забвение), кровь как след, пугающие сцены. При первом запуске — предупреждение;
> жестокость можно уменьшить (пауза → «Глухомань» → «Жестокость: меньше»).

Хоррор с сюжетом для **Minecraft Java 1.21.1 (Fabric)** от **Yompix Games**. Создатель — **Yompix**.
Играется одному или с друзьями (2–4, через LANTERN, «Открыть для друзей» или свой сервер).

Октябрь 1996-го. Тебя наняли ночным сторожем на мёртвую лесовозную узкоколейку «Ветка 41», которую режут на металлолом,
и велели снимать её каждую ночь на видеокамеру. В 3:14 по путям без рельсов приходит поезд, которого видно только в видоискателе.
Наутро тот, кто в него сел, исчезает — и с ним исчезает память о нём. Помнит только кассета. А кассеты каждое утро забирают из ящика на станции.

Дизайн всей истории: [`docs/DESIGN_v2.md`](docs/DESIGN_v2.md). Журнал работы: [`docs/LOG.md`](docs/LOG.md). Звуки: [`docs/SOUND_CREDITS.md`](docs/SOUND_CREDITS.md).

## 0.4 — часть первая: пролог и две ночи
- **Пролог «Проверка записи»** (ночь 1): сразу в видоискателе, `REC ● 14.10.1996 02:51`. Снимаешь перрон, стрелку, переезд,
  баба Поля машет из окна. Рельсы обрываются, дальше в лес — голые шпалы и босые следы. На мёртвой линии звонит переезд.
  Крючок — не позже двух минут.
- **Глава I «Еловый»**: утро, дом бабы Поли заколочен «лет пять как», соседи её не помнят. Решение у ящика: сдать кассету
  (батарейки и новая кассета) или оставить. Интервью с жителями на камеру. В 22:00 — правила по громкоговорителю (одно ложное).
  **Ночь на перроне**: лунатики идут к поезду, ты их останавливаешь без оружия. Утром — пересмотр плёнки.
- **Камера** (ПКМ — к глазу): в видоискателе виден поезд и рельсы там, где их сняли; глазами — Обходчик, которого нет в кадре.
  Батарея садится, **G** — ИК-режим (видно в темноте, садит батарею втрое). Узкий кадр, REC, мигающая точка, батарея, счётчик кассеты.
- **Плёнка — это память**: кассета E-180 = 6 сюжетов, сервер пишет, кто был в кадре. Снятый житель «заякорен» — поезд не может
  его позвать, пока кассета у тебя. Полная кассета — новая запись **стирает** старую (что стирать — выбираешь сам).
  ПКМ по кассете — список сюжетов: ▶ пересмотреть, ✕ писать поверх.
- **Ящик**: сданная кассета — это список посадки (поймёшь не сразу). Ночью зовут самых заметных на сданных плёнках, а если сдавать
  нечего — того, кого меньше всех снимали.
- **Табло рельсовых цепей** в дежурке горит без тока: где поезд, где Обходчик, где лунатик. Щёлкают реле. В соло Захар диктует по рации.
- **Правила из громкоговорителя**: одно — ложь. Проверка: сними объявление и пересмотри — на плёнке ложное правило «молчит».
- **Ночь на перроне**: разбудить (ПКМ по лунатику и держаться рядом 3 с, не бежать), снять на ходу (3 с в кадре),
  колокол (все замирают — один раз), две стрелки (поезд уходит на обгонный путь — каждая один раз). Прятаться в пустом вагоне — нельзя.
- **Обходчик**: глазами виден и ходит; в камере его нет, но пока на него смотрит поднятая камера — он не двигается.
  Учится: приходит туда, где ты чаще опускаешь камеру и прячешься. Вне кадра и в одиночку — вырывает плёнку, потом забирает.
- **Кооператив**: камера одна на бригаду; оператор видит поезд, остальные — Обходчика. Роли: оператор, дежурный, стрелочник, фонарщик.
  Лунатиков столько, сколько игроков (до трёх).
- **Кат-сцены**: поезд из тумана в видоискателе; баба Поля садится и смотрит в объектив; пересмотр ночной записи.
- **VHS**: в видоискателе — полная плёнка (мягкие полосы трекинга внизу, срыв строк рядом с Обходчиком, выпадения),
  глазами — лёгкий фильтр (выключается). Реплики — субтитрами (озвучки пока нет).
- Старые твари 0.3 ушли из сюжета: Жердь → Обходчик, Хор → лица в окнах Порожняка, Двойник → Лишний (во второй части).
  Метеостанция и шахта убраны.

## Установка (для игрока)
Скачай `Glukhoman-Full-<версия>.zip`, распакуй и запусти `INSTALL.bat` — всё ставится само (Fabric, Fabric API, GeckoLib внутри мода,
оптимизация, по желанию шейдеры). Подробно — `Прочитай.txt` в архиве. Потом: **Новый мир → Ещё → Тип мира: «Глухомань»**.
Мир 0.3 не подходит — создай новый.

С друзьями через LANTERN: хозяин открывает мир «Глухомань» и делится им как LAN-миром.
Свой сервер: Fabric-сервер 1.21.1 + Fabric API + мод в `mods`, в `server.properties` — `level-type=glukhoman\:taiga`.

## Управление
- ПКМ с камерой — поднять к глазу / опустить; **G** — ИК-режим; ПКМ по кассете — список записей.
- ПКМ по людям — поговорить (с камерой у глаза — интервью на плёнку), ночью — разбудить лунатика.
- ПКМ по ящику, колоколу, стрелкам, табло, стулу в дежурке. **R** — фонарик, **H** — подсказка направления.
- Настройки — кнопка «Глухомань» в меню паузы.

## Для разработчика
- Сборка: `./gradlew build` → `build/libs/glukhoman-<версия>.jar`.
- Ресурсы 0.4: `tools/gen_v2.py` (Обходчик, Порожняк, жители, блоки, звуки), `tools/story_v2.py` (тексты → `glukhoman_story.json`),
  `tools/gen_resources.py` (модели, переводы, sounds.json, тип мира), `tools/gen_real_sounds.py` (записи BigSoundBank).
- Сюжет: `story/Story.java` (пролог, глава I), `story/Night.java` (ночь на перроне, табло, учёба Обходчика), `story/Tapes.java`
  (кассеты), `story/Cam.java` (камера на сервере). Карта: `world/MapBuilder.java`, `world/Terrain.java`.
- Клиент: `client/Viewfinder.java` (видоискатель, ИК, рельсы-призраки), `client/mixin/VisibilityMixin.java` (кто что видит),
  `client/Cine.java` и `client/Trailer3.java` (кат-сцены), `client/Hud.java` (REC, батарея).
- Тесты: `./gradlew runServer -Pservertest` (сервер проходит пролог и ночи 1–2), `-Pautotest=shots|models|trailer|join|watch` (клиент).
- Трейлер: `-Pautotest=trailer` (кадр за кадром в ffmpeg) → `tools/make_trailer3.py` (70 с + три вертикальных ролика).
