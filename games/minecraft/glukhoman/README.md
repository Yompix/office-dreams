# Глухомань

Хоррор с сюжетом для **Minecraft Java 1.21.1 (Fabric)** от **Yompix Games**. Создатель — **Yompix**.
Играется одному или с друзьями (2–4, через LANTERN, «Открыть для друзей» или свой сервер).

Тайга, октябрь 1996-го. Посёлок, который все зовут Глухоманью, закрытая метеостанция «Полынь-17» и старая шахта.
Метеоролог Анна Ветрова пропала, а в эфире звучит её голос: «Не отвечайте, если позовут по имени…»

Сюжет и дизайн: [`docs/STORY.md`](docs/STORY.md). Журнал работы: [`docs/LOG.md`](docs/LOG.md).

## Что внутри
- **5 глав, 2 концовки и эпилог**: «Приезд», «Голоса», «Просека», «Глубокая», «Хор». Цели на экране, записки,
  плёнки и рация с озвучкой и субтитрами, названия глав, чекпоинты.
- **Рукотворная карта**: посёлок с избами, сельсоветом, школой, гаражом и подстанцией; кладбище; просека с избушкой
  охотника; метеостанция с мачтой и бункером; шахта с копром, лифтом и штольнями. Вокруг — тёмная тайга.
- **Три существа**: Жердь (двигается, только когда не смотришь), Слухач (слепой, охотится на звук — крадись),
  Хор (финал).
- **Рассудок**, сердцебиение и виньетка, туман и цвет неба по главам, мерцающий свет, тряска камеры,
  события «за спиной», шёпот и шаги, стук в дверь.
- **Фонарик с батарейкой** (R), керосиновый фонарь с маслом, камешки, чтобы отвлечь Слухача, безопасные комнаты.
- **Сложность**: «Жутко», «Страшно», «Кошмар». **Доступность**: меньше скримеров, без вспышек, подсказка направления (H).
- Кооператив: сюжет общий на сервере, кто угодно двигает историю, рассудок выше рядом с друзьями.

## Установка (для игрока)
Мод отдельно: [`download/glukhoman-0.1.0.jar`](download/glukhoman-0.1.0.jar) (нужны Fabric Loader 1.21.1 и Fabric API). Не запускается — [`download/FIX-Glukhoman.bat`](download/FIX-Glukhoman.bat).

Скачай `Glukhoman-Full-<версия>.zip`, распакуй и запусти `INSTALL.bat` — всё ставится само (Fabric, Fabric API, мод).
Подробно — `Прочитай.txt` в архиве. Потом: **Новый мир → Ещё → Тип мира: «Глухомань»**.

С друзьями через LANTERN: хозяин открывает мир «Глухомань» и делится им как LAN-миром (свой Paper-хост LANTERN моды Fabric не грузит).
Свой сервер: Fabric-сервер 1.21.1 + Fabric API + мод в `mods`, в `server.properties` — `level-type=glukhoman\:taiga`.

## Управление
- R — фонарик, H — подсказка направления, ПКМ по предметам на карте — взять/прочитать/включить.
- Shift — красться (Слухач не слышит), ПКМ с камешком — бросить.
- Настройки — кнопка «Глухомань» в меню паузы.

## Для разработчика
- Сборка: `./gradlew build` → `build/libs/glukhoman-<версия>.jar`.
- Ресурсы: `tools/gen_resources.py` (модели, переводы, звуки, тип мира — папка `data` тоже генерируется),
  `tools/gen_textures.py`, `tools/gen_sounds.py`, озвучка — `tools/voice.py` (XTTS-v2, реплики берутся из `glukhoman_story.json`).
- Архивы: `python3 tools/make_full.py 0.1.0` → `Glukhoman-Full-…zip` и `Glukhoman-Mods-…zip`.
- Карта: `world/Terrain.java` (рельеф, лес, дороги) и `world/MapBuilder.java` (постройки).
- Сюжет: `story/Story.java`, тексты — `src/main/resources/glukhoman_story.json`.
- Автотест: `-Dglukhoman.autotest=shots` (клиент) и `-Dglukhoman.servertest=1` (сервер).
