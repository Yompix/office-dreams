## 0.2.0 (14 ноя 2026) — «как в кино»

Сделано:
- Исследование хоррор-модов и машинимы: `docs/RESEARCH.md`.
- GeckoLib 4.8.4 (вшита в мод). Модели и анимации генерирует `tools/gen_geo.py`: Жердь (13 анимаций), Слухач (10), Хор (9),
  люди — скелет и захват движения из Новограда + свои жуткие (still, slowwave, turn180, twitch, knock, jumpscare). Светящиеся глаза.
- Существа: общий класс `HorrorMob` (действие-анимация, исчезание анимацией, гашение ламп рядом). Жердь: следует на расстоянии →
  охотится (один игрок — раньше), выглядывает из-за ствола, наклоняет голову, если долго смотреть, отступает от луча фонаря.
  Новый Двойник (облик Анны или друга со скином и ником). Слухач поворачивает голову на 180°, дёргается.
- Кат-сцены (8): вступление, стук (рапид + долли-зум), посёлок одним кадром (фонари гаснут), коридор (бег Жерди + скример),
  Анна (мимика, перевод фокуса, пыль), бункер (Хор поднимается, лучи), «Тишина» (кран, разрыв неба), «Эхо» (наезд, двойник-ты).
  Камера каждый кадр (миксин Camera), FOV/наклон, игроки скрыты, ввод заблокирован, пропуск синхронный.
- Пост-эффект страха, полноэкранный скример, тишина перед скримером, ложный вылет, дрожь руки с фонарём, история без слов
  (плакаты, царапины, куклы, фото; старые миры дооснащаются при запуске), 6 новых звуков.
- Настройки: эффекты экрана (выкл/слабо/полностью), ложный вылет; «меньше скримеров» заменяет полноэкранный скример тряской.

Проверено:
- `./gradlew build`; сервер `-Pservertest`: SERVERTEST PASS 30/30 со всеми кат-сценами (сервер ждёт их длину).
- Клиент под xvfb (`-Pautotest=shots2`): все 8 кат-сцен, скримеры, крупные планы; видео двух сцен — `/tmp/claude-0/glukhoman-shots2/`.
- Два клиента на выделенном сервере: кат-сцена стартует у обоих в одну секунду, сюжет общий.

Не сделано:
- Модели существ — из кубов (генерируются кодом), не ручная лепка в Blockbench; анимации — процедурные ключи.
- Зеркала/отражения, тени от динамического света — не делали (без шейдер-модов это дорого).
- Связка с Sodium по-прежнему не проверена в настоящем лаунчере (пост-эффект может отключиться — игра не упадёт).


## 0.1.0 (14 ноя 2026)

Сделано:
- Каркас мода (Fabric 1.21.1, loom 1.11.8, Fabric API 0.116.6, Java 21) по образцу Новограда, без GeckoLib — модели существ на ванильных ModelPart.
- Тип мира «Глухомань» (`glukhoman:taiga`): свой генератор (рельеф, ели и сухостой, река, дороги, площадки), тёмный биом с пеплом в воздухе, граница мира 1000×1000.
- Карта строится кодом при первом запуске (~2 с): старт у обрушенного моста и УАЗ, посёлок (дом Анны, магазин, сельсовет, школа, гараж, подстанция, водокачка, 3 брошенные избы, фонари), кладбище, избушка охотника, метеостанция (радиорубка, кабинет Шумова, генераторная, мачта 36 м), бункер под мачтой (зал с колоннами, 3 усилителя, передатчик), шахта (копёр, клеть, 4 штольни с крепью, убежище № 3).
- Сюжет: 5 глав, 24 шага с целями, сцены (стук в дверь, ночь без рассвета, погоня из станции, лифт, побег от Хора), 2 концовки + эпилог + титры. Записки (11) открываются книгой и кладутся в инвентарь. 31 реплика озвучена XTTS-v2 с обработкой (рация, плёнка, Хор, шёпот).
- Существа: Жердь (видение / охотник, двигается только когда не смотрят, телепорт за спину), Слухач (слепой, идёт на шум, крадущихся замечает только вплотную, повторяет голоса), Хор (босс, неубиваемый, оглушается лучом фонаря, полоса босса), Анна (NPC).
- Механики: рассудок (тьма/свет/друзья рядом/безопасные комнаты/существа, паника на нуле), шум (бег, двери, ломание, камешки, усилители), фонарик с батарейками и керосинка с маслом (свет — невидимые блоки света, видно всем), камешки, режиссёр страха (звуки за спиной, двери, гаснущий свет, стук, голос из леса, шёпот, фигура у кромки леса, редкий скример), мягкая граница главы («лес не отпускает»), чекпоинты, режим «Приключение» (карту не сломать).
- Клиент: туман и цвет неба по главам, тёмные ночи (своя яркость), виньетка и красный пульс, сердцебиение, дыхание, тряска камеры, затемнения, названия глав, субтитры, стрелка-подсказка (H), галлюцинации на низком рассудке, звуковой фон по месту (лес/посёлок/станция/шахта/бункер/погоня/страх/облегчение), выключена музыка Minecraft.
- Настройки: сложность (Жутко/Страшно/Кошмар), меньше скримеров, без вспышек, субтитры, сердцебиение, подсказки, яркость.
- Все звуки и текстуры — генераторы в `tools/`.

Проверено:
- `./gradlew build` — без ошибок.
- Выделенный сервер Fabric (`./gradlew runServer -Pservertest`, `level-type=glukhoman:taiga`): мод грузится, карта строится за ~2 с, «игрок-призрак» проходит ВЕСЬ сюжет 30/30 шагов до концовки «Тишина» (лог: SERVERTEST PASS).

- Настоящий клиент на выделенном сервере (`-Dglukhoman.autotest=join`, вход по localhost): экран сложности приходит с сервера, глава I стартует, вход в дом меняет цель, ПКМ по рации — субтитры и голос Анны, через 25 с цель «Найти батарейки…», команда главы 3 — титр «Просека».
- Кооператив двумя клиентами одновременно (`join` + `watch`): второй игрок видит ту же главу и цель, получает обновление цели после действий первого и титр главы III.
- Клиент под xvfb (`-Dglukhoman.autotest=shots`, встроенный сервер = «Открыть для друзей»/LANTERN): 10 снимков атмосферы по главам.
- Архивы: `python3 tools/make_full.py 0.1.0 /tmp/claude-0/glukhoman-release`.

Не сделано / дальше:
- Связка с Sodium/ImmediatelyFast из архива в настоящем (не dev) клиенте не запускалась — миксины мягкие (defaultRequire 0), игра не упадёт, но туман стоит проверить.
- Тонкая настройка скорости существ и баланса батареек — по отзывам игроков.
- Английский и украинский — только названия предметов/клавиш, сюжетные тексты пока только на русском.
