# Достижения в Google Play Игры (как у Minecraft в Плей Маркете)

В самой игре достижения уже работают: плашка «Достижение получено» с картинкой и экран «Достижения» в меню (на сайте, в APK, на ПК). Чтобы они ещё появлялись в профиле **Google Play Игры** (значок с кубком на странице игры в Плей Маркете, уведомление Google сверху экрана), нужно один раз завести их в Play Console. Это можете сделать только вы — со своего аккаунта разработчика.

## Что сделать в Play Console (≈20 минут)

1. Play Console → ваше приложение **Hush Till Six** → слева **Рост → Сервисы Play Игр → Настройка и управление → Конфигурация** (Play Games Services → Setup and management → Configuration).
2. «Использует ли игра API Google?» → **Нет, игра не использует API Google** → **Создать** (создастся проект Play Игр).
3. **Учётные данные → Добавить учётные данные → Android**: тип «Android», выберите приложение `com.yompix.hushtillsix`. Попросит «Сертификат SHA-1» — возьмите **SHA-1 ключа подписи приложения**: Play Console → Тестирование и выпуск → **Настройка → Целостность приложения → Подпись приложения** → строка «SHA-1» в блоке «Сертификат ключа подписи приложения». Сохраните.
4. **Достижения → Добавить достижение** — 21 раз, по таблице ниже: название, описание, значок (файл `<ID>.png` из папки, что я прислал), очки, «Скрытое» — как в таблице. «Пошаговое» — **нет**. Язык по умолчанию — английский; русский/украинский — кнопка «Добавить перевод».
5. После всех 21: **Опубликовать** (вкладка «Публикация» в Сервисах Play Игр). Пока не опубликовано — видят только тестировщики.
6. Пришлите мне две вещи: **ID проекта Play Игр** (12 цифр — «ИД приложения» на странице «Конфигурация») и **список ID достижений** (на странице «Достижения» есть кнопка «Получить ресурсы» / Get resources — скопируйте весь текст оттуда). Секретов и паролей там нет.
7. Я вставлю это в приложение и соберу новый `.aab` — дальше обычное обновление в Play Console.

Очки: всего 830 из 1000 возможных (Google разрешает до 1000 на игру, каждое — кратно 5).
