# Проверка помещений и дверей (WHAT THE LAKE KEEPS)

Зонды запускаются из папки игры: `--script` с полным путём к файлу, параметры игры — после `--`.
Без экрана — через `xvfb-run -a -s "-screen 0 1280x720x24"`; рендер `--rendering-driver opengl3 --rendering-method gl_compatibility`.

## План сверху и срез на высоте тела — `probe_plan.gd` + `plan_check.py`

Когда начнётся прогулка с нужным id, зонд снимает план сверху (`plan_<id>.png`) и срез: что твёрдое между
«пол + `--slicebot`» и «пол + 1,7 м» (герои, частицы и надписи спрятаны) — `mask_<id>.png`, плюс данные прогулки
(`plan_<id>.json`). Проверка ищет твёрдое внутри области, где может быть тело героя (прямоугольники ходьбы минус
препятствия, с допуском 3 см), печатает скопления в метрах и рисует `chk_<id>.jpg` (лиловое — место, куда можно зайти).

```
cd godot/lake
xvfb-run -a -s "-screen 0 1280x720x24" godot --rendering-driver opengl3 --rendering-method gl_compatibility \
  --resolution 960x540 --path . --script ../../tools/lake/qa/probe_plan.gd -- \
  --autoplay --scene c3_s3_noah --planid c3v --snapdir /путь/планы [--slicebot 0.25]
python3 ../../tools/lake/qa/plan_check.py /путь/планы c3v
```

`--slicebot`: на улице 0,45 (снег по колено не считаем), в комнатах 0,25 (лавки, сундуки, кровати).
Прогулки и сцены, с которых их снимать (5 ноя): `st24` — `s5`; `c3p` — `c2_s4` (кафе строит эта сцена, с `c2_s4_porch`
зал пустой); `storm` — `c2_storm_wait`; `c3v` — `c3_s3_noah`; `c3h` — `c3_s4`; `c4v` — `c4_s1_van`; `c4b` — `c4_s3`;
`c4i` — `c4_s7`; `c4s`, `c4a` — `c4_sana`; `c5d`, `c5h` — `c5_s1`.

## Дверь глазами игрока — `probe_door.gd`

Сцена `s5` идёт сама (автопрогон), заправка в начале прогулки пропускается, дальше Ной ходит «клавишей W»
(камера поворачивается к следующей точке): открыть дверь как по E, внутрь в обход створки, подождать, пока доводчик
закроет, изнутри к выходу, отойти, снова внутрь, прямо в открытую створку, наружу, назад в закрывающуюся. Каждый кадр —
расстояние от оси тела до полотна створки; итог `DOOR route …: min …, кадров ближе 0,22: …` (0,22 м — радиус тела).
С `--write-movie` получается запись прогона.

```
xvfb-run … godot … --write-movie /путь/door.avi --fixed-fps 12 --path . --script ../../tools/lake/qa/probe_door.gd -- \
  --autoplay --quality 0 --scene s5 --snapdir /путь
```

«Не дошёл» — нормально, если точка за створкой или в полке: Ной упирается, а не проходит сквозь.

## Герой в точке и снимки — `probe_pose.gd`

`--pose x:z:угол[:клип]` и `--cams x:y:z:tx:ty:tz:fov,…` — снимки `pose_N.png` из нужных мест (например, Ной у вала
снега в деревне).
