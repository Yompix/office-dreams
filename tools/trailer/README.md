# Трейлеры «Hush Till Six»

Четыре ролика: YouTube 16:9 (~95 с) и TikTok 9:16 (~45 с), русский и английский.
Все кадры рисует движок игры (`World.draw`, графика «Кино»), голоса — озвучка игры (`snd/`, `snd/en/`),
музыка — кодом (`tools/music/compose.py`, мотив «ля-фа-ми-ре»), звуки — `snd/*.mp3`. Без ИИ-картинок и чужой музыки.

```
cd public/games && python3 -m http.server 8771 --bind 127.0.0.1 &
bash tools/trailer/make.sh tt ru OUT      # потом tt en, yt ru, yt en (английская берёт часть кадров из русской)
```

- `edl.js` — монтаж: сегменты (кадр игры, секунда анимации, наезд камеры, подпись камеры наблюдения), реплики, звуки, надписи.
  Правила режут реплику сменщика `dg08` по словам — между правилами паузы.
- `render.js` — кадры 3D в кэш (`CACHE/<ключ>/`), 24 к/с, камера наблюдения 12 к/с. Перемонтаж пересчитывает только изменённые сегменты.
  `--preview` — по 3 кадра на сегмент в малом размере, лист — `python3 tools/trailer/sheet.py CACHE/preview`.
- `probe.js` — какие сегменты одинаковы на двух языках (нет надписей, никто не говорит в кадре): их кадры английская версия берёт из русской.
- `audio.py` — звук: голоса с эффектами как в `engine.js` (телефон, рация, стекло, «чужой» голос), музыка по отметкам монтажа
  (завязка → правила → нарастание → смерти → тишина → бросок → название → звонок → карточка), музыка уходит под голос,
  отчёт «речь против фона» по каждой реплике, итог −14 LUFS.
- `comp.js` — сборка кадра: зерно, виньетка, интерфейс камеры наблюдения, помехи, бросок, субтитры, правила, название, финальная карточка
  («Играй сейчас на itch.io», «Скоро в Steam и на Android», 18+). `--png DIR --at 12.5,40` — снимки кадров для проверки надписей.

Рендер 3D — около 2 с на кадр Full HD на 4 ядрах: YouTube ≈ 1 ч, TikTok ≈ 30 мин на язык.
