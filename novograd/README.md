# Новоград: Тёмные улицы

Криминальная история в открытом мире для **Minecraft Java 1.21.1 (Fabric)** от **Yompix Games**. Отдельный мод, который можно поставить рядом с LifeCraft.

## Что внутри

- **Остров Новоград 2000×2000.** Свой генератор мира: деловой центр с небоскрёбами, старый город, порт, пляж с пальмами, промзона «Чёрных Ящеров», пригород, холмы и лес, аэродром, кольцевая трасса. На улицах светофоры, остановки, скамейки, урны.
- **Сюжет: 3 акта, 23 миссии, с озвучкой.** Кат-сцены живые: герои ходят, садятся в машины, едут, дерутся и стреляют, камера летит за ними.
  1. **Уличные гонки.** Брат Джейк, Ники «Нитро», Сторм, клуб «Неон» и Роза, механик Винс и перерезанные тормоза, облава.
  2. **Чёрные Ящеры.** Брик, налёт на разборку, контейнер из порта, предложение Марко «Синего», казино «Корона», бронефургон, предательство.
  3. **Под прикрытием.** Лейтенант Питерсон, техник Томми, журналистка Лена, продажный шеф Харрис, похищение, погоня до аэродрома.
- **100 побочных миссий.** Телефон (G) → «Задания».
- **Свободная игра как в GTA:**
  - розыск ★–★★★★★: патрули, машины с мигалками, блокпосты с 3★, вертолёт с прожектором с 4★, спецназ с 5★; задержан / погиб;
  - оружие: пистолет, пистолет-пулемёт, дробовик, автомат «АК», снайперка с прицелом, гранаты, коктейль Молотова, нож, бита; бронежилет и аптечки; колесо оружия (TAB), стрельба из машины;
  - транспорт: машины (угон, тюнинг, нитро, покраска), мотоцикл, катер, вертолёт, самолёт;
  - подработки за рулём (J): такси и патруль на полицейской машине;
  - 50 тайников, трюковые прыжки, 6 убежищ на продажу, коды `/cheat`.
- **Радио в машине.** 4 своих станции с ведущими: «Неон 88», «Бит Улиц», «Ночной Порт», «Трасса 128».
- **Радар** слева внизу: цель, маршрут по улицам, полиция и банды.
- **Фишки Новограда:** кино-камера в машине (B) и живые кат-сцены.
- **Графика:** листва на ветру, вода с волнами и бликами, кинофильтр (всё настраивается).
- **Свой интерфейс:** заставка, главное меню, пауза, телефон, настройки игры.

## Установка

1. Fabric Loader для Minecraft 1.21.1 и Fabric API.
2. Мод [`download/novograd-0.2.0.jar`](download/novograd-0.2.0.jar) положить в `mods`.
3. **Новый мир → Ещё → Тип мира: «Новоград: Город»** → Создать. Остров появится сам, а сюжет начнётся с заставки.

Играть с другом: меню паузы → «Открыть для друзей» (через интернет нужен мод e4mc).

## Управление

- G — телефон, M — карта, TAB (держать) — колесо оружия, ПКМ — стрелять, R — перезарядка (в машине — радио).
- Машина: N — нитро, L — фары, Z/X — поворотники, C — аварийка, H — гудок, «-»/«=» — громкость радио, J — подработка, B — кино-камера.
- Вертолёт: Space — вверх, Shift — вниз, W/S — вперёд/назад, A/D — поворот. Самолёт: W/S — газ, Space/Shift — нос вверх/вниз.
- Настройки игры — в главном меню и в паузе.

## Для разработчика

- Остров: `world/Island.java` (районы, улицы, здания по координатам) и `world/IslandChunkGenerator.java`.
- GTA-механики: пакет `gta/` (`Wanted`, `Weapons`, `Crime`, `Streets`, `Garage`).
- Сюжет и 100 побочных миссий: `tools/story.py` → `novograd_story.json`. Побочные миссии — `story/SideMissions.java`, GTA-шаги — `story/GtaSteps.java`.
- Озвучка: `tools/voice.py` (XTTS-v2, лицензия Coqui CPML — некоммерческая).
- Автотесты: `-Dnovograd.autotest=tour|story|side|gta`.
