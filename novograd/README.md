# Новоград: Тёмные улицы

Криминальная история в открытом мире для **Minecraft Java 1.21.1 (Fabric)** от **Yompix Games**. Отдельный мод, который можно поставить рядом с LifeCraft.

## Что внутри

- **Остров Новоград 2000×2000.** Свой генератор мира, остров строится на ходу:
  - деловой центр с небоскрёбами;
  - старый город;
  - порт с контейнерами и кранами;
  - пляж;
  - промзона «Чёрных Ящеров»;
  - пригород;
  - холмы и лес;
  - аэродром;
  - кольцевая трасса.
- **Сюжет: 3 акта, 12 миссий, с озвучкой.**
  1. **Уличные гонки.** Брат Джейк, Ники «Нитро», соперник Сторм.
  2. **Чёрные Ящеры.** Босс Брик, угон, засада в порту, ограбление бронефургона, предательство.
  3. **Под прикрытием.** Лейтенант Питерсон и хакер Томми: жучок, погоня до аэродрома, финальная перестрелка.
- **100 побочных миссий.** Телефон (G) → «Задания»:
  - гонки Ники;
  - угоны на заказ;
  - дела Питерсона;
  - войны за районы;
  - курьерка Томми;
  - тест-драйвы Джейка;
  - тайники;
  - испытания розыском.
- **Розыск ★–★★★★★.**
  - Полиция пешком и на машинах с мигалками и сиреной, с трёх звёзд стреляет.
  - Скройся из виду — звёзды гаснут, или перекрась машину в Нитро-Гараже.
  - Поймали — «ЗАДЕРЖАН» (штраф, оружие изымают). Погиб — больница.
- **Оружие.** Пистолет, автомат и бита продаются в «Калибре» (18+). Есть кровь, паника прохожих, банды отстреливаются.
- **Машины.**
  - Можно угнать любую машину, выкинув водителя.
  - Нитро (N), фары (L), поворотники (Z/X), аварийка (C).
  - У машины есть «здоровье»: дым, огонь, взрыв.
  - Тюнинг: двигатель, броня, покраска.
- **Живые улицы.** По тротуарам ходят прохожие, по улицам с поворотами ездят машины.
- **Карта (M).** Весь остров с районами, цель задания и стрелка-компас.

## Установка

1. Fabric Loader для Minecraft 1.21.1 и Fabric API.
2. Мод [`download/novograd-0.1.0.jar`](download/novograd-0.1.0.jar) положить в `mods`.
3. **Новый мир → Ещё → Тип мира: «Новоград: Город»** → Создать. Остров появится сам, а сюжет начнётся с заставки.

Играть с другом: меню паузы → «Открыть для друзей» (через интернет нужен мод e4mc).

## Управление

G — телефон (там «Задания»), M — карта, N — нитро, L — фары, Z/X — поворотники, C — аварийка, H — гудок, R — радио, K — графика (красивая / лёгкая / выкл). ПКМ с пистолетом — выстрел, держать ПКМ с автоматом — очередь.

## Для разработчика

- Остров: `world/Island.java` (районы, улицы, здания по координатам) и `world/IslandChunkGenerator.java`.
- GTA-механики: пакет `gta/` (`Wanted`, `Weapons`, `Crime`, `Streets`, `Garage`).
- Сюжет и 100 побочных миссий: `tools/story.py` → `novograd_story.json`. Побочные миссии — `story/SideMissions.java`, GTA-шаги — `story/GtaSteps.java`.
- Озвучка: `tools/voice.py` (XTTS-v2, лицензия Coqui CPML — некоммерческая).
- Автотесты: `-Dnovograd.autotest=tour|story|side|gta`.
