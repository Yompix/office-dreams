## Не готово (по мастер-промпту)

1. **Ядро по архитектуре мастер-промпта** (этап B): отдельные autoload `StoryState` (все флаги с типами и
   диапазонами в одном месте), `SaveManager` (версия формата, ручные слоты), `SceneFlow`, отладочная панель (F3: глава,
   сцена, флаги, доверие, «Тень», доказательства, какая концовка сейчас выходит). Сейчас всё это — внутри `game.gd`
   (≈1850 строк), флаги объявлены по главам в `data/ch*.json`, сохранение одно + снимки контрольных точек.
2. **Озвучка 28 реплик без голоса** (+ 23 отложенные правки английских реплик) — нужен ответ владельца. До тех пор — субтитры.
3. **Доступность действий:** переназначение клавиш, «облегчённые действия» / автоуспех (сейчас есть только «длинные
   выборы» ×1,6).
4. `ASSET_REGISTER.md`, character bible / visual bible в формате мастер-промпта (часть есть в `newgame/BIBLE.md`,
   `newgame/DESIGN.md`), `TEST_PLAN.md` целиком (ветки — уже в `BRANCH_TESTS.md`), README проекта.
5. Постановка новых ремарок: текст есть, отдельных анимаций под них нет (см. `DIALOGUE_AUDIT.md`, последний раздел).

## Известные проблемы

- Запуск сразу с середины главы (`--scene` не с начала главы и не с точки сохранения) не расставляет героев —
  постановка пишет ошибки. Только для отладки; в игре такого пути нет.
- 16 журнальных флагов ни на что не влияют (перечислены в `BRANCH_CONTINUITY.md`).
