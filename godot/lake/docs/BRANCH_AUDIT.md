## §38 мастер-промпта: семь «проблемных мест»

Редактор просил не считать их ошибками без проверки. Итог: ошибок в логике нет; четыре строки рассказчика
поправлены (без голоса, озвучка не нужна), одна — без изменений, потому что уже сделано.
