# WHAT THE LAKE KEEPS — проверки персонажей и анимации (1 ноября)

Всё ниже запускалось в этом проходе; что не проверялось — сказано прямо. Как устроено — `ANIMATION_SYSTEM.md`,
причины дефектов — `CHARACTER_AUDIT.md`.

## 1. Как повторить

```
source tools/godot/env.sh
python3 tools/lake/anim_suite.py              # стенд: простой, шаг, переходы, повороты, пауза, переноска → /tmp/lake_anim_suite.json
python3 tools/lake/anim_suite.py --perf       # нагрузка 8 героев (без другой нагрузки на машину)
python3 tools/lake/story_sim.py all && JOBS=3 python3 tools/lake/story_tests.py   # 33 маршрута в Godot
$GODOT --headless --path godot/lake --script res://scripts/dev/gaze_probe.gd       # куда поворачивается голова
```

Стенд — `scenes/dev/anim_lab.tscn` (кадры: `-- --lab carry --view side --shots ПАПКА`). Замер «до» — ядро героя до
этого прохода (`git show f155781:godot/lake/scripts/actor/actor.gd`, с добавленными счётчиками стенда) на временной
копии стенда без теста переноски: `LAB_SCENE=res://scenes/dev/<копия>.tscn python3 tools/lake/anim_suite.py --nocarry`
(копия и старое ядро в репозиторий не входят — два класса `Actor` в одном проекте нельзя). Шаг кадра у всех замеров
один — 1/60 с (`--fixed-fps 60`), чтобы «скачок за кадр» был тем, что видит игрок при 60 кадрах.
