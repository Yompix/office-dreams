# WHAT THE LAKE KEEPS — сохранения: аудит и исправления

1–2 ноября, главное ТЗ (этап 14). Код — `scripts/game.gd` (`_save`, `_load_save`, `_read_save`, `_resume_at`),
восстановление по главам — `ChN.restore()`; проверки — `scripts/dev/input_test.gd` (`--savetest A…E`).

## 1. Как устроено
* Контрольная точка — сцена с `"save": true` (в начале сцены, до её начислений флагов): `user://lake_save.json` =
  `{"v": 2, "scene", "flags", "lang", "clock"}`. «Продолжить» сбрасывает флаги к значениям из данных, накладывает
  сохранённые, восстанавливает видимое по флагам (`_resume_at` + `ChN.restore`) и проигрывает сцену с начала —
  ничего не начисляется второй раз (проверка B).
* Отдельно: `user://lake_checkpoints.json` (дерево выборов, «переиграть отсюда»), `user://lake_progress.json` (карта глав
  и журнал концовок), `user://lake_settings.cfg` (настройки).

## 2. Ошибки → причина → исправление
| № | Ошибка | Причина | Исправление |
|---|---|---|---|
| S-01 | Падение игры или выключение посреди записи портило сохранение — «Продолжить» пропадал | файл писался поверх | запись во временный файл → прошлое сохранение в `.bak` → подмена; при чтении: не JSON / нет флагов / сцены нет → запасная копия; поле версии формата `v` |
| S-02 | Дэнни после загрузки в s7 и главах 2–5 — без рации | при загрузке создавался без неё, а главы вешают рацию только новым | рация вешается при создании Дэнни в `_resume_at` |
| S-03 | Потерявшийся в буран Дэнни возвращался в дом после загрузки утра (`c3_s6`) | проверялся только флаг `danny`, не `danny_lost`; `in_house` ставил всех | `danny_lost` в `_resume_at` и `in_house` |
| S-04 | Загрузка у озера после приезда седана (`c5_s4`, `c5_s4_alone`, `c5_mama`, `c5_shore`, концовки): Хейл говорил без тела, седана нет | их создавал только эффект приезда в `c5_s3` | `Ch5.restore` ставит седан, Хейла и санитара у берега сразу (`_sedan(g, true)`: без проезда, звука мотора и выхода из машины) |
| S-05 | «Продолжить» в `c5_oblivion` → ошибка скрипта в `hale_takes` | обращение к Хейлу без проверки | проверка `has(g, "hale")` |
| S-06 | Концовки на льду (`c5_shadow`, `c5_shadow_dark`, `c5_ice`) после загрузки — без тёмного льда и полыньи, а Айрис ставилась к полынье | префиксы сцен льда не включали эти | префиксы дополнены |
| S-07 | Младенец пропадал: загрузка `c3_s4` при умершей Еве (у Айрис), утро `c3_s6` | `_house_sleepers` давал его только Еве; `in_house` не создавал | Евы нет — у Айрис; утром — у матери или у Айрис (`Ch4.baby_holder`) |
| S-08 | Браслет Зои (надет в `c2_s2_ride`, не в контрольной точке) после загрузки пропадал | не восстанавливался | надевается при загрузке с `c2_s3` и дальше |
| S-09 | Часы в машине после загрузки — «03:12» | в сценах без поля `time` оставалось значение по умолчанию | время часов пишется в сохранение и ставится при загрузке |
| S-10 | Язык сохранения перебивал выбранный в настройках | язык брался из файла | язык — из настроек (из файла — только у старых сохранений без настроек) |

## 3. Проверки
Результаты — `FINAL_QA_REPORT.md` §4 (запуски `--inputtest --savetest A…E` один за другим, общий `user://`):
* A — сохранение на входе в пост = флаги на входе; после выбора — сохранение `c2_s4` с выбором;
* B — «Продолжить»: флаги как при сохранении, без повторного начисления;
* C — раннее сохранение → другой выбор: следов первого нет;
* D (новая) — испорченный основной файл → запасная копия `c5_s4`: Хейл, санитар и седан у берега, лёд, часы из сохранения;
* E (новая) — `c3_s6` с `danny_lost`: Дэнни не появляется в доме; младенец на руках.

## 4. Ограничения
* «Продолжить» после ТИТРОВ повторяет последнюю концовку (последняя контрольная точка — сама концовка или берег);
  другие концовки — через «Дерево выборов → переиграть отсюда».
* Новая игра перезаписывает сохранение сразу (пролог — контрольная точка) без вопроса; удаления прогресса в меню нет.
* Внутреннее состояние глав (`c2…c5`: что лежит на столе, горит ли печь) не сохраняется — восстанавливается постановкой
  сцены с начала; поэтому контрольные точки стоят только в начале сцен.
