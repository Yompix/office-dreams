## Обязательные условия

1. Сюжет, пять концовок, важные события, существующие выборы и работающие механики сохраняются.
2. Никаких массовых изменений до утверждения эталонной заправки.
3. Резервная копия `assets/` от 4 ноября — неприкосновенна. Перед изменениями проверять наличие доступной копии и
   контрольных сумм. Облачная копия не считается проверенной на восстановление, пока архив не скачан и не проверен.
4. Не выдавать автоматические проверки за живое прохождение.
5. Каждое выполненное изменение подтверждать кадрами или видео из реальной игры.
6. Не начинать следующий этап, если предыдущий не прошёл проверку.
7. Сохранять исходные файлы и вести журнал изменений.

### Уточнения редактора перед разработкой

1. Шаги 1–6 эпизода 1 — без управления, с шага 7 игрок заправляет машину; момент передачи управления обозначить явно.
2. Длительность пересчитать по реальному прохождению после реализации, а не по сумме секунд.
3. В точке с ведром — только ведро с водой для мытья стёкол и тонким льдом: ни раковины, ни крана, ни другой ёмкости.
4. Кровь на руках — три состояния по порядку: засохшая → чистые ладони с тёмным под ногтями → разбитые костяшки после
   провала.
5. Предметы действительно взаимодействуют с руками и телом, а не просто появляются и исчезают.
6. Видео готовой сцены — полный эпизод от приезда до отъезда, хотя бы с одним вариантом ветвления и с ведром.

  пускает). Проверка — у владельца на ПК: скачать архив, распаковать в пустую папку и в PowerShell выполнить из неё

  ```
  Get-Content SHA256SUMS.txt | % { $h, $p = $_ -split '  ', 2; if ((Get-FileHash "godot/lake/$p" -Algorithm SHA256).Hash.ToLower() -ne $h) { "НЕ СОВПАЛО: $p" } }
  ```

  Пустой вывод — все 1208 файлов совпали. До такой проверки облачная копия считается непроверенной.
