# WHAT THE LAKE KEEPS — звук: аудит и исправления

1–2 ноября, главное ТЗ (этап 11). Аудит — чтение кода и проверка файлов (`ffmpeg volumedetect`); исправления — код
(`scripts/audio.gd`, `scripts/game.gd`, `scripts/chapter4.gd`, `scripts/ui/hud.gd`) и данные звука.

## 1. Как устроено
* Голос: один плеер на шине Voice, реплика по ключу из `data/vo_lines.json`; длина, слова и громкость — `snd/vo/<язык>/timing.json`;
  губы — по буквам слова и огибающей громкости (25 Гц). Озвучено 271 из 299 реплик на обоих языках (28 правились после записи).
* Музыка: своя, кодом (`tools/lake/music.py`): тема меню, тема конца главы; песня по радио — шина SFX.
* Фоны — «грядки» (`bed`): игра каждый кадр задаёт нужную громкость каждой петли (салон, лес, буран, заправка, кафе, гул,
  радио, шаги), громкость сама плавно идёт к ней. Разовые звуки — пул из 12 плееров. Шины Music / SFX / Voice, ползунки — верные.
